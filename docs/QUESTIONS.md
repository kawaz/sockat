### RM-Q1: README の「短いパスは今までどおり標準にそのまま渡します」を、DR-0019 に合わせて言い直すか

README-ja.md の「返ってくるのは標準と同じ型で、短いパスは今までどおり標準にそのまま渡します。」の文 (英語版も同じ箇所)。[DR-0019](decisions/DR-0019-absolutize-relative-path-on-bind.md) で、bind と resolve は短い相対パスを絶対パスにしてから標準に渡すようになったので、相対パスの bind では「そのまま」が字面どおりでなくなった。標準に渡ること、ソケットのファイルができる場所、返る型は変わらない。

- 文の役目は「短いパスでは sockat を挟んでも何も変わらないので、置き換えて損が無い」と伝えること。読者 (困って来た人) にとって、綴りが相対か絶対かはこの段の関心でない
- 相対パスが絶対になる話を README に足すと、「注意」の枠に近づく (AGENTS.md の「守ること」)

- [ ] a: 「そのまま」だけを外す (「短いパスは今までどおり標準に渡します」)。嘘が無くなり、軽さも変わらない (統括の推し)
- [ ] b: 今のまま置く (この段の読者には十分に正しい)
- [ ] c: 相対パスは絶対にして渡すことを 1 文足す
