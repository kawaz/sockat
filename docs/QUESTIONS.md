## 裁定待ち

### D13-Q1: any 系の `losses` に `cwd-relative` を足すか

相対パスで標準の bind を通ると、カーネルは相対の綴りを覚える。後で cwd を変えてからその綴りで unlink / stat すると別の場所に当たる。sockat が失わせたものでなく標準が元から持つ危険で、any 系は何が起きたかを利用者が知るための API なので、知らせる価値はある。範囲を広げることになる。名前は足すだけで壊れないので、後から足してもよい ([DR-0013](decisions/DR-0013-any-means-reach-at-any-cost.md))。

統括推し: a。any 系を選んだ利用者は、何を失ったかを知りたくて選んでいる。

- [ ] a: 足す。相対パスで標準の経路を通った bind に `cwd-relative` を付ける
- [ ] b: 足さない。sockat が経路で失わせたものだけを挙げる
