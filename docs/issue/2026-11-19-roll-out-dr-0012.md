# DR-0012 を SPEC の残りと各言語に行き渡らせる

## ハブで残っていること

- [x] D をどこにも作れない時の bind も D 無しの形でスレッド cwd → /proc 版 → fork (D12-Q1 = a、DR-0012 と SPEC に反映済み)
- [x] README (日英) の「共通の振る舞い」を DR-0012 の経路に合わせる
- [x] connect の fork と FreeBSD の connectat は D を通さない (D12-Q2 = a、反映済み)
- [x] SPEC を経路の名前と失うもので組み直す、使ってはいけない書き方の節
- [x] any 系を `_ex` に統合する (kawaz 裁定、DR-0015)。3 言語の作り直しは依頼する
- [x] 経路の名前の変更 (fork → fork-cwd 等、symlink → symlink-file / symlink-dir) と、bind の symlink-file (kawaz 裁定、DR-0016)。3 言語の作り直しは依頼する
- [ ] connect の試す順番を、書き込みもスレッドも要らない経路を先にする案 (外部の指摘、議論中)
- iOS 等 macOS 以外の Apple の OS は [2026-11-19-ios-long-path-bind](2026-11-19-ios-long-path-bind.md) に分けた (kawaz が iOS で試す機会ができた時に決める)
- 言語によらない適合試験は [2026-11-19-cross-language-conformance-test](2026-11-19-cross-language-conformance-test.md) に分けた

## 各言語の状態

- 3 言語に依頼済み: connect の順の作り直し (DR-0012)、`_ex` への統合 (DR-0015)、経路の名前の変更と bind の symlink-file (DR-0016)。実装・試験・文書を合わせて commit まで、push / version は待ち
- sockat-py は 0.1.5 を PyPI に公開済み (DR-0012 より前の経路。asyncio の後始末が元のパスで消す)。connect の順の作り直しは済み
- 適合試験 (ハブの `just conformance`) は 3 言語の CLI がつながり、最初の 14 場面で差なし。作り直しのたびに各言語が流して報告する
- release は、上の作り直しが 3 言語で済み、適合試験で差が無くなってから kawaz に OK をもらう (sockat-rs 0.4.0、sockat-go 0.3.0、sockat-py 0.1.6 の見込み)
